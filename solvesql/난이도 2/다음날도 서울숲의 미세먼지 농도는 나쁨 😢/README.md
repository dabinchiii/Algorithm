### table

- `measurements`
  - date `measured_at`
    : 측정 일시
  - string `station`
    : 측정소명
  - number `no2`
    : 이산화질소(NO2) 농도(ppm)
  - number `o3`
    : 오존(O3) 농도(ppm)
  - number `co`
    : 일산화탄소(CO) 농도(ppm)
  - number `so2`
    : 아황산가스 농도(ppm)
  - number `pm10`
    : 미세먼지(PM10) 농도(㎍/㎥)
  - number `pm2_5`
    : 초미세먼지(PM2.5) 농도(㎍/㎥)
